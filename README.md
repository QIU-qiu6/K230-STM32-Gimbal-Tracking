# K230 + STM32 双轴绿色色块追踪云台

基于 K230 图像处理和 STM32F103C8 双轴速度控制的绿色色块追踪实例。摄像头随云台转动，使目标保持在画面中心。

## 已有功能
- K230：800×480 RGB565、上下翻转、LAB 绿色阈值检测、选择最大色块、屏幕标记。
- 串口：115200 8N1，目标帧 `X:<cx>,Y:<cy>,W:<w>,H:<h>` 加换行；无目标发送 NO_TARGET 加换行。
- STM32：双轴比例速度控制、8 像素死区、电机位置查询、俯仰软限位、急停与 OLED 状态。
- 当前 Ki、Kd 为零；没有实现 YOLO、场景记忆、姿态稳定或三维建图。

## 接线（来自代码，PCB 尚待对应确认）
- K230 IO5 TX -> STM32 PA3 RX；K230 IO6 RX <- STM32 PA2 TX。
- USART1 PA9/PA10 对应水平电机；USART3 PB10/PB11 对应俯仰电机。
- 电机端口丝印与固件版本须以实际驱动器说明核对。系统共地。
- PA0 为低电平有效急停输入。具体电源、电平与 PCB 接线尚未在本次整理中核实。

## 构建与验证状态
firmware/stm32 包含用户提供工程的应用源码和 Keil 工程文件。工程引用外部 ARM/CMSIS 与 Keil.STM32F1xx_DFP.2.2.0 目录，需要配置依赖路径。本次没有重新编译或上板验证。没有打包旧 HEX、构建日志、调试缓存和个人 IDE 布局。
firmware/k230 为用户提供的原始视觉脚本，没有改变运行逻辑。请使用兼容 media.sensor/media.display 的 CanMV 固件，并根据实物光照调整阈值。

## 已知问题（静态检查）
1. zdt_proto.c 接收最多 32 字节并复制至调用方 16 字节数组，异常长响应可越界。
2. 目标丢失时停止命令结果未检查，随后清除 tracking，停止失败后没有持续重试。
3. 电机串口为阻塞等待，超时可能拖慢控制与急停响应。
4. 当前 PID 积分条件与死区冲突，未来启用 Ki 前需修正。
5. 开机当前位置被当作软件零点；俯仰范围与齿轮传动关系须按实物校准。
6. 最大色块策略可能切换目标，单帧漏检会触发停转。
